# CHAPTER 3 — 아무도 보지 않은 곳

> 구현 기준: `src/game/content/chapter03/` · 시나리오 테스트: `chapter03.test.ts`
> 노드 79 · 엔딩 5 · Case Memory 「보지 않은 곳은 없는 곳이 아니다」

## 로그라인

추석이 지나고 열흘. 엿새째 열이 나는 일흔여섯 할머니가 서울의 딸 집에서 응급실로 온다. 소변에 백혈구가 있고, 읍내 의원 항생제는 듣지 않았다. 모두가 요로감염이라고 한다. 답은 속옷 선 아래, 아무도 보지 않은 곳에 있다.

## 의학적 핵심 — 쯔쯔가무시병

- *Orientia tsutsugamushi*. 털진드기 **유충**이 문다. 우리나라는 가을(10~11월)에 몰리고, 벌초 · 성묘 · 밭일 · 논일이 대표적인 노출이다.
- 잠복기 약 6~21일(흔히 10일 안팎). 이 장의 시간표: 벌초 추석 사흘 전 → 발열 추석 네댓새 뒤(잠복 7~8일) → 입원 추석 열흘 뒤(발병 6일째). 이웃 박영자는 입원 다음 날 발열 사흘째(잠복 약 12일).
- 고열, 두통, 근육통, 몸통에서 시작하는 반점구진 발진, 림프절 비대, 결막 충혈. 노인은 혼돈으로 온다.
- **가피(eschar)**: 통증도 가려움도 없는 검은 딱지. 겨드랑이, 사타구니, 허리띠 · 속옷 선, 여성은 유방 아래처럼 **옷에 가려진 접히는 곳**에 잘 생긴다. 찾으려면 옷 속까지 봐야 하고, 그러려면 먼저 물어야 한다.
- 혈액: 혈소판 감소, 간효소 상승, 경한 저나트륨. 흉부 사진의 간질성 음영. 소변 백혈구는 열에서도 나온다(아질산염 음성).
- 신속항체검사는 **발병 첫 주에 음성일 수 있다.** 확진은 가피 PCR, IFA 항체 4배 상승.
- 치료는 **독시사이클린**, 의심되면 결과를 기다리지 않는다. 세팔로스포린 같은 베타락탐은 세포 안 균에 닿지 않는다.
- 합병증: 간질성 폐렴 · ARDS, 쇼크, 뇌수막염, 급성 신손상.

감별진단과 이 장에서의 단서

| 감별 | 맞지 않는 단서 |
| --- | --- |
| 요로패혈증 | 아질산염 음성, 혈소판 · 간 · 폐 · 피부를 방광 하나로 설명 못 함, 세팔로스포린 실패 |
| 알로퓨리놀 과민반응(DRESS) | 3주 전 시작이라 시기는 맞지만 **호산구 1%**. 스테로이드를 쓰면 감염이 나빠진다 |
| 렙토스피라증 | 논일은 맞지만 신기능 · 황달이 약하다 |
| 신증후군출혈열 | 창고의 쥐는 맞지만 **단백뇨 없음** |
| SFTS | 진드기, 혈소판 감소는 맞지만 PCR 음성. 혈액 접촉 전파라 결과 전까지 접촉주의 |

## 핵심 선택

- **가피를 찾는 방법** (`ESCHAR_ASK`) — 간호사와 함께, 한 군데씩 묻고 본다(신뢰 +) / 딸에게 부탁 / "잠깐이면 됩니다" 바로 걷는다(**존엄 침해** `dignity_breached`) / 넘어간다. 찾기는 관찰 판정(DC 7)이다.
- **가피는 한 번의 주사위에 잠기지 않는다.** 못 찾으면 새벽에 간호사가 찾는다. 대신 중증 경과였다면 진단은 `late`로 기록된다.
- **경험적 독시사이클린** — 가피를 찾았거나, 벌초 노출을 알고 추론 · 기전 · 병력 중 하나가 3 이상이면 결과 전에 시작할 수 있다. 응급실에서 시작해야만 치료 시점이 `appropriate`.
- **음성 신속항체** (`RDT_001`) — 1장 기억 「정상은 진단이 아니다」가 말한다.
- **스테로이드 함정** — 약물 과민반응으로 고정하고 스테로이드를 쓰면 열이 잠깐 내렸다가 다시 치솟는다. 끝까지 밀면 실패(`FAIL_001`).
- **삽관 결정** (`DET_AIRWAY`) — 그녀가 대답할 수 있는 몇 분. 본인에게 묻기(신뢰 +6) / 딸과만 정하기 / 설명 없이 준비(존엄 침해).
- **이웃** (`NEIGH_CALL`) — "오늘 바로 큰 병원에 가세요. 벌초했다고 꼭 말씀하시고, 딱지를 봐달라고 하세요." 2장 기억 「환자는 한 명이 아니다」가 영자를 떠올리게 한다.
- **사과** (`ETHICS_DIGNITY`) — "찾아야 할 게 있었어도, 먼저 여쭤봤어야 했습니다." 존엄 침해는 사과로만 회복된다.

## 연결

- 1장 기억 → 음성 신속항체 앞에서. 2장 기억 → 추석 이후를 물을 때 "같이 풀밭에 앉은 사람".
- 이 장의 기억 「보지 않은 곳은 없는 곳이 아니다」: 진찰은 환자가 보여준 곳에서 끝나지 않는다. 먼저 묻고, 끝까지 본다.

## 비주얼 슬롯 (모두 미촬영)

장면 `SCN3_001_ER_NIGHT`(er-night) · `SCN3_002_ICU_BAY`(icu) · `SCN3_003_WARD_MORNING`(ward). 증거 `EVD3_001_ESCHAR`(진찰 기록 메모), 추석 사진 `EVD3_002_GRAVE_PHOTO` · `EVD3_003_DOG_PHOTO` · `EVD3_004_PADDY_PHOTO` · `EVD3_005_STORE_PHOTO`. 가피 사진은 임상 사진이 아니라 진찰 기록의 스케치로 남긴다(노출 부위 촬영 금지).

## 테스트가 고정하는 것

이상적 경로 → A · 노출을 알면 가피 전에도 독시사이클린 · 못 찾은 가피는 간호사가 찾고 `late` · 음성 신속항체와 1장 기억 · 동의 없는 진찰과 사과 → C · 이웃을 놓치면 D · DRESS 고정 → 실패 · IFA 대기 → 지연.
