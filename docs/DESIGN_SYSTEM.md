# 디자인 시스템 — 비가 그친 뒤 (AFTER THE RAIN)

화면은 한 장의 사진과 그 위에 놓인 종이다. 사진은 화면 끝까지 채우고, 읽는 면은 종이(paper), 기기처럼 떠 있는 정보는 어두운 유리(glass)다. 모든 규칙은 `src/app/globals.css`의 토큰에서 시작한다.

## 1. 원칙

1. **화면을 채운다.** 스테이지는 `100dvh` 전체. 사진이 없으면 CSS로 연출한 무대(backdrop)가 채운다. 가운데 좁은 카드, 위아래 빈 여백을 만들지 않는다.
2. **밝게 읽힌다.** 기본은 종이색(`--paper #f3efe7`)과 형광등 아래 병원. 밤 장면도 방은 밝고, 시각은 창밖·시계·도장으로 알린다. 완전한 암전은 프롤로그와 고백 장면처럼 짧은 순간에만.
3. **탭이 진행이다.** 한 걸음 앞으로 가는 선택은 버튼이 아니다. 화면 어디를 탭해도 다음 비트로 넘어가고, 대화 상자 오른쪽 아래에 작은 `›` 힌트(필요하면 짧은 동사 "정리한다")만 둔다. 진짜 선택일 때만 카드가 나온다.
4. **정보는 제자리에.** 바이탈은 모니터에, 수치는 기록지에, 메시지는 메모에, 단서는 차트에. 같은 정보를 두 번 보여주지 않는다.
5. **숫자는 숨긴다.** 판정 확률, 신뢰도 수치, 점수를 보여주지 않는다. 결과는 "통했다 / 닿지 않았다", 도장(적절·지연·확인 못 함), 인물의 반응으로 전달한다.

## 2. 토큰

### 색

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--paper` / `-2` / `-3` | `#f3efe7` `#e9e3d8` `#dcd4c5` | 읽는 면, 시트, 챕터 카드 |
| `--card` | `#fbf9f4` | 선택지, 사건 기록 카드 |
| `--ink` / `-2` / `-3` | `#1b2129` `#434e59` `#78818a` | 본문, 보조, 캡션 |
| `--glass` / `-2` | `rgb(13 18 23 / .46)` `/.72` | HUD 버튼, 장소 표시, 힌트 |
| `--teal` `--red` `--amber` `--blue` `--moss` | | 상태·강조. 한 화면에 두 가지 이상 쓰지 않는다 |
| `--ab-*` | 능력별 7색 | 속마음 라벨, 판정 태그, 판정 토스트 |
| `--tone-*` | 인물별 7색 | 화자 이름과 앞의 짧은 선 |

보라색 그라데이션, 네온, 순수 검정 배경 위 흰 글씨 본문은 쓰지 않는다.

### 서체 — 세 목소리

| 토큰 | 서체 | 목소리 |
| --- | --- | --- |
| `--serif` | Gowun Batang | 서술(17px/1.8), 속마음, 말하는 선택지, 챕터·장소 제목 |
| `--sans` | IBM Plex Sans KR | 대사(17px/1.7, 500), 행동 선택지, UI |
| `--mono` | IBM Plex Mono | 시각, 바이탈, 검사 기록지, 케이스 번호 |

- 한국어 줄바꿈은 `word-break: keep-all`. 한 비트는 모바일에서 세 줄 안쪽.
- 영문 캡션(`CASE 03`, `ENDING A`, `FIELD INVESTIGATION`)은 모노, 자간을 넓혀 작게. 한국어 제목 옆의 보조로만.

### 형태와 움직임

- 모서리: 선택지 12px, 대화 상자 16px, 시트 20px(위쪽만), HUD 버튼 12px.
- 이징 `--ease: cubic-bezier(.22,.8,.26,1)`. 등장은 0.4~0.6초, 사라짐은 더 짧게.
- 배경은 켄 번스(천천히 확대)와 크로스페이드. 무대 CSS는 블라인드 빛, 빗줄기, 창밖 행인 같은 작은 움직임 하나만.
- `prefers-reduced-motion`에서는 모든 움직임을 끄고, 사라지는 요소는 제거 타이머로 치운다.

## 4. "AI가 만든 것 같지 않게" — 금지 목록

기계적으로 생성된 인터페이스의 흔한 신호를 피한다.

- ❌ 가로로 긴 "계속", "화면 탭", "다음" 버튼. → 화면 탭과 작은 힌트.
- ❌ 모든 것을 둥근 반투명 카드에 넣기, 카드 안의 카드. → 종이, 유리, 사진 세 재질만.
- ❌ 보라-파랑 그라데이션, 네온 글로우, 과한 그림자, 이모지 아이콘. → 선 아이콘(`icons.tsx`), 실제 사물의 색.
- ❌ 모든 요소 가운데 정렬. → 읽는 글은 왼쪽 정렬, 제목은 장면마다 자리(장소 캡션은 좌상단, 챕터 카드는 가운데).
- ❌ "✨ 새로운 단서를 발견했습니다!" 같은 과장된 시스템 문구. → `단서 · 엿새째 고열`.
- ❌ 모든 문장을 같은 길이로. → 짧은 대사, 끊어지는 서술, 가끔 한 단어.
- ❌ 능력명을 영어 약어로 노출(OBS, EMP). → `◉ 관찰`, `∿ 공감`처럼 기호와 한국어.
- ❌ 점수, 등급, 퍼센트. → 도장과 인물의 반응.
- ❌ 모든 장면에 같은 배경. → 장소마다 다른 무대, 같은 장소는 같은 무대(연속성).

## 5. 접근성

- 터치 대상 최소 44px. 선택지 최소 높이 54px.
- 탭 레이어는 버튼(`aria-label="다음"`). 키보드는 Space · Enter · →로 읽고, 1~9로 선택지를 고른다.
- 토스트는 `role="status"`. 시트와 증거 확대는 포커스를 가두고 Esc로 닫히며, 확대 중에는 배경이 `inert`.
- 색만으로 상태를 전달하지 않는다. 모니터 경고는 색과 깜빡임, 도장은 색과 글자.
- 증거의 정확한 값은 항상 HTML 텍스트로 있다.
